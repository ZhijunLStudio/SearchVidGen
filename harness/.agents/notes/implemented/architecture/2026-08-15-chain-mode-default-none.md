# Agent Note: 段间衔接默认 none（帧级硬约束已被实验否决）

Status: implemented

## Problem

多段故事片需要"上下文携带"保证角色/场景延续。最直觉的方案是帧级硬衔接：
段 i 末帧 → 段 i+1 首帧条件（H3 fl2va），追求"结构性连续"。但画面级连续
不等于好的剪辑——需要实验验证哪种衔接策略让**观众体验**（而非像素相似度）更好。

## Decision

`chain_mode` 默认 **none**（纯文本延续：下一段指令携带角色/场景的文本描述），
并保留 hard / ref 作为对比实验变体。依据实验证据：

| 模式 | 跨段一致性 | 叙事推进 | 段均分 | 结论 |
|---|---|---|---|---|
| hard（fl2va 首帧硬衔接） | 10.0 | **1.0（冻结帧）** | 10.0 | 过度约束 |
| none（t2va 文本延续） | 10.0 | 10.0 | 10.0 | 本故事最优 |
| ref（ref2va 参考软衔接） | 9.2（首段衔接 5.0，锚点图弱） | **10.0** | 10.0 | 允许切镜；一致性强依赖参考图质量 |

（E3/E8/E10，同一故事"雨夜小猫"控制变量对比。叙事推进维度由跨段评测量化：
相邻段首尾帧对比 + 裁判判定"是否为合理新镜头"。）

结论：段间衔接**不应做帧级硬约束**。默认 none；当有高质量角色/风格参考图时
ref 是更强的一致化工具（锚点质量决定一致性下限）。

## Alternatives considered

- **默认 hard**：否决。跨段一致性满分（10.0）掩盖了冻结帧跳切——
  裁判指出衔接帧"几乎一模一样"。一致性与叙事推进是一对张力，硬约束只优化前者。
- **默认 ref**：否决。ref2va 一致性强依赖参考图质量（E10 首段衔接 5.0 即锚点图弱），
  且部署成本高（需要 int8 配方/独立环境，见 ref2va 笔记）；作为默认会放大
  参考图质量的方差。
- **移除 hard**：否决。它作为"过度约束"的对照基线仍有价值，且 fl2va 在
  特定场景（如产品演示的固定机位）可能合理。

## Consequences

- `tasks/story.yaml` 与两个 bench 变体固化三种模式，`scripts/compare_chains.py`
  按 run 内 config.yaml 快照自动聚合对比。
- 2026-08-16 起能力校验按 chain_mode 推导要求（hard→first_last_frame、
  ref→refs、none→无），替换原先硬编码的 first_last_frame 校验（见
  声明式能力与路由笔记）。
