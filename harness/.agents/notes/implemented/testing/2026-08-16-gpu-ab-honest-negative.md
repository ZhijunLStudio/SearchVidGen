# Agent Note: GPU 级因果 A/B 的诚实负结果（E38）

Status: implemented

## Problem

E37 证明经验在剧本层有效（+0.70），但 E34 的下游问题仍在：
经验是否改善跨段一致性？用 repeats 基建 + 同 seed 控制变量，
唯一变量 = memory.path，n=2/臂，4 格真实 GPU 运行。

## Decision

跑完后如实记录（不挑数据）：臂均分 A=4.5 vs B=7.5——方向反号、
n=2 下不可检出。结论与经验沉淀：

1. **效应逐层衰减**：上游（剧本 +0.70 因果）→ 下游（画面层）效应
   低于噪声水平；E16/E23 的 none 模式方差（2.0-10.0）是主导因素。
2. **样本量门槛**：臂内方差 ±3.5 下，检出 3 分臂间差需 n≈8-10/臂
   （≈200+ 分钟 GPU）——当前成本不划算，列为未来大样本研究。
3. 实验设计本身保留（bench_memory_ab.yaml 入库）：同 seed、同 query、
   memory.path 轴 + repeats——未来样本充足时直接加 repeats 即可。

## Alternatives considered

- **不公布负结果**：否决。证据库的原则是记录一切（E 系列的成立基础）；
  负结果防止未来重复投入。
- **加样本量硬跑 8/臂**：否决。200 分钟 GPU 换一个"下游效应 < 噪声"
  的更精确上界，ROI 不成立；剧本层因果（E37）已支撑学习机制的价值。

## Consequences

- 自学习的故事线完整且诚实：机制有效（E37）、下游未检出（E38）——
  学习价值定位在剧本质量，不夸大画面层收益。
- bench_memory_ab.yaml 作为可复用 A/B 模板留在 tasks/。
