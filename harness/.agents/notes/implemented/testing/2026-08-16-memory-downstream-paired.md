# Agent Note: 记忆下游效应配对复测——E38 重访（E44）

Status: implemented

## Problem

E38 的诚实负结果：记忆对下游（画面层跨段一致性）的效应低于噪声，
检出需 n≈8-10/臂（200+ 分钟 GPU），结论"上游有效≠下游可测"。
但 E38 跑在三个噪声源未分离的年代：剧本 API 温度 0.9（四格四个剧本）、
臂内无种子对齐、裁判随机性未量化。E42（裁判 sd=0）+ E43（同种子
生成 MAE=0）把三个噪声源全部消除——E38 的下游问题应当用配对设计
重测：唯一变量 = memory.path，同种子对齐生成噪声，剧本温度 0 +
无剧本评审 → 臂内完全确定性，n=1/臂即可读出处理效应（若有）。

## Decision

1. **配对设计**（tasks/story_memory_check.yaml + bench_memory_paired.yaml）：
   - 剧本温度 0 + script_judge 空 → 剧本差异 = 记忆注入差异（干净
     处理效应），臂内剧本逐字一致；
   - 两臂同种子（20260816）→ 生成噪声逐像素对齐；
   - 裁判确定性（E42）→ 分数差异无采样误差；
   - 2 段（跨段一致性需要段对）、chain none、t2va 20 步 5s。
2. **测量面**：臂间剧本 diff、逐段视频 MAE、segment 评分、
   cross_consistency 评分（下游主指标）。
3. **审计顺带发现与修复**：检查"任务 memory.path 是否与生产记忆
   文件一致"时，先误判为路径分裂（cwd vs base_dir），深挖后确认
   `exp.base_dir / path` 解析一直正确、生产记忆完好（种子轮 n_exp=5）。
   真正缺口：**显式配置的记忆文件缺失时静默空记忆启动**——若生产
   记忆真丢失，自学习闭环会静默失效。修复：`Experiment.warn()`
   公开警告通道 + director 记忆缺失可见化（事件流 + console）。
   **修复当天即立功**：本实验首版任务把路径写成
   `experiments/_memory.jsonl`（与 base_dir 双重拼接），A 臂将空跑——
   缺失警告在第一格启动时立刻报出，止损于 1 分钟生成之内。

## Alternatives considered

- **继续 E38 的 n=8-10 大样本路线**：否决。配对设计把方差问题
  消掉而不是硬堆样本——E42/E43 的确定性证据让大样本变成浪费。
- **臂内重复 2 次**：否决。臂内确定性的前提下 n=1 就是点估计，
  重复只验证确定性本身（E43 已证）。

## Consequences

- **实测（n=1/臂，配对设计）**：
  - 剧本：两臂 video_prompt 逐段不同（记忆注入改变剧本——处理效应
    在位；B 臂明显缺失"段间机位/景别变化"规则）；
  - 段视频 MAE=39.67/段（处理效应传播到像素层，同种子下差异=纯
    剧本驱动）；
  - segment 评分：两臂均 10.0/10.0（段级裁判对优质视频天花板饱和，
    无区分力，呼应 E42）；
  - **cross_consistency（下游主指标）：A=10.0/10.0 passed，
    B=跨段一致性 3.0 failed——+7.0 的下游效应**。
- **结论**：E38 的"下游效应低于噪声"是**噪声假阴性**——配对设计
  消除剧本/生成/裁判三层噪声后，记忆的下游效应清晰可测（本故事
  本种子上 +7.0）。因果链闭合：记忆→剧本（E37 +0.70）→视频差异
  （MAE 39.67）→跨段一致性（+7.0）。方向/幅度随故事与种子而变，
  方法论结论（配对设计可检出 E38 检不出的下游效应）不依赖此点估计。
- **诚实边界**：n=1 是点估计；效应泛化需要多故事/多种子复测——
  但配对设计让每次复测只需 2 格（~45 分钟），复测成本已可行。
  **E45 复测结果（当前现实）**：第二故事（雪山邮差）Δ=0.0——+7.0
  未复现，效应是故事条件性的：记忆的下游价值为**防护性**（空臂
  剧本产出冻结帧式重复段时防住失败），非普遍加分。
- 记忆缺失可见化：显式路径缺失 → warning 事件（A/B 空臂同样
  警告，属预期噪音）；未来生产记忆丢失会在事件流里留痕。
- 测试 +1（161 total）；新任务/基准两个文件（可重跑）。
