# Agent Note: 记忆下游效应复测（第二故事）——E44 泛化检验（E45）

Status: implemented

## Problem

E44 在单故事单种子上测得 +7.0 下游效应（cross_consistency A=10.0
vs B=3.0），并诚实声明：n=1 是点估计，方向/幅度可能随故事而变。
E44 的方法论结论（配对设计可检出 E38 检不出的效应）不依赖点估计，
但"记忆对画面层有效"的强度主张需要第二个故事检验——否则一次
有利结果不足以把 E38 的负结果翻成普遍正面结论。

## Decision

1. **同设计复测**：bench_memory_paired.yaml（唯一变量 memory.path、
   同种子/温度 0/无剧本评审），换全新 query（雪山邮差与金毛犬）。
2. **工具固化**：scripts/compare_arm_pairs.py——配对 A/B 臂间对比
   的通用分析器（剧本 diff / 逐段 MAE / segment+cross 评分 / 维度
   Δ 表），在 E44 数据上回验一致（Δ=+7.0）后用于本实验。

## Alternatives considered

- **多种子一故事 vs 多故事一种子**：本轮先做第二故事（故事多样性
  是对"下游效应存在"更强的检验）；多种子同故事留作效应大小
  分布研究。
- **并入 E44 一轮**：否决。每轮一个实验 + 完整验证与笔记，
  证据粒度与决策节奏匹配。

## Consequences

- **实测（第二故事，雪山邮差与金毛犬）**：
  - 剧本逐段不同（处理效应在位），段视频 MAE=62.28/72.43；
  - segment 评分两臂均 10/10；**cross_consistency 两臂均 10.0/10.0
    passed——Δ=0.0**。
- **结论：效应是故事条件性的，不是普遍的**。E44 的 +7.0 复现失败
  （本故事空臂剧本恰好自然保证段间变化，无需记忆规则也通过）。
  综合 E44+E45：记忆的下游价值是**防护性的**——当空臂剧本恰好
  产出冻结帧式重复段时，记忆规则防住失败（E44 +7.0）；当故事本身
  自然分段时，效应为 0（E45）。E38 的"下游低于噪声"翻案为：
  "下游效应存在，但条件于故事是否触发规则"。
- **韧性实战（一次 bench 三次中断）**：①外部整树击杀（22:06，共享
  机器，无 EXIT 行）；②裁判服务被外部击杀（GPU7 被回收，httpx
  ConnectError 响亮失败）；③重启裁判后格级续跑两次 → 完成。
  E22/E29 的续跑纪律同日两次兑现；RUNBOOK 裁判重启命令原样有效。
- **顺带修复（E45 逮住）**：裁判宕机中断续跑后，缓存命中的段
  跳过评测且无记录——证据缺口静默。修复：缓存命中无评测记录 →
  记占位 error 记录（`_has_seg_judge_record` + 占位 save_eval）。
- 证据工具链 +1：compare_arm_pairs.py（配对 A/B 通用分析器，
  在 E44 数据上回验一致）。测试 +2（163 total）。
